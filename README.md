# Client-Side-Coursework
University groupwork website. Split work between 3 people.

The Espresso is a responsive coffee shop website developed as part of a university group project. The aim of the project was to design and build a modern, user-friendly website using core front-end web technologies.

The website allows users to explore the coffee shop, browse its menu, learn more about the business and get in contact through an online form.

Features
Responsive design for desktop, tablet and mobile devices
Home page showcasing the coffee shop and popular drinks
Interactive menu with different coffee categories
About Us page with information about the business
Contact page with form validation
Mobile-friendly navigation menu
Interactive elements and animations

My Contribution

My main responsibility within the group project was designing and developing the About Us page.

I created the page using HTML, CSS and JavaScript, focusing on both the visual design and user experience. The page includes:

Hero section
Our Story section
Company values
Team section
Statistics section
Interactive FAQ section
Call-to-action section
Responsive navigation
Mobile-friendly responsive design

Working on this page allowed me to develop my skills in front-end development, responsive web design and creating interactive website components while working as part of a development team.

Technologies Used

HTML5 – website structure and content
CSS3 – styling, layouts and responsive design
JavaScript – interactivity and dynamic functionality
Web3Forms – contact form submission

About the Project

This project was completed collaboratively as part of my university studies. Each group member contributed to different areas of the website, allowing us to practise collaborative development while combining our individual work into one complete website.

My individual contribution was primarily the About Us page, which I designed and implemented while ensuring it remained consistent with the overall theme and navigation of the rest of the website.

Maintaining a consistent design across multiple webpages
Working collaboratively on a shared software project
